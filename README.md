Project Overview
This repository contains my Week 10 ChronoVault: Pixel Breaker project developed in Visual Basic .NET. The purpose of this project is to recreate a classic arcade-style Brick Breaker game while documenting the complete development process, planning, testing, and evidence required for the assignment.

Run Action
1.	Open ChronoVault-Pixel Breaker.slnx in Visual Studio 2022.

Expected Result
The application launches successfully and displays the ChronoVault: Pixel Breaker game window. During the preparation phase, the project opens correctly and serves as the foundation for the completed Brick Breaker game.
